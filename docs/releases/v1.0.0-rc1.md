# ChaosLab v1.0.0-rc1 — GitHub Release Notes 草案

**仅说明草案，尚无 tag / GitHub Release。** Release preparation R1 不等于历史 M1-R1。审批流程和实际状态见 [发布检查表](../22-v1-release-checklist.md)。

ChaosLab 是 Java + React 教学型混沌工程平台，展示实验配置、受控生命周期、恢复证据、审计与可追溯报告。这个 RC 面向本地学习和作品集演示，不是可直接公网开放的生产故障平台。

## 主要功能

Session / CSRF / VIEWER 与 ADMIN；持久化 Fake 全流程、参数/SafetyGuard 校验、幂等及占用、自动恢复；审计、报告及来源/数据质量；独立 SHA 历史投影；跨平台本地启动与只停止自有会话的工具。

本地模式不需要 Docker、VMware、MySQL、sudo 或 ChaosBlade。没有默认管理员或密码。真实故障权限不随 ADMIN 角色开放。

## 环境与快速开始

完整 JDK21（正确 `JAVA_HOME`）、Node24/npm、Git、联网下载首次依赖。Windows11/Ubuntu；macOS 未验收。仓库放自己的私有用户目录，尤其注意 Windows NTFS ACL。

以下用于**未来获批的 tag**；tag 目前不存在，不要提前执行 checkout：

```text
git clone https://github.com/8xbAdx8/ChaosLab.git
cd ChaosLab
git checkout v1.0.0-rc1
```

Windows：`scripts/start-fake.ps1`；Ubuntu：`bash scripts/start-fake.sh`。仅本次 PowerShell RemoteSigned 入口和环境配置详见 [交付指南](../18-v1-delivery.md)，不要更改系统全局策略。

首次自行选择用户名，现有 Java 工具隐藏读取两次密码，保存 BCrypt hash，不保存明文。账号配置在忽略的 `.local/dev/accounts.json`，后续复用。打开 `http://127.0.0.1:5173/login`。

创建 Fake CPU 草稿 → 编辑 → 校验 → 预检 → 启动 → 停止/自动恢复 → 生成报告。`percent=10` 是参数，不是观测 CPU10%；SIMULATED 不升级成 physical VERIFIED。无目标指标则 NOT_COLLECTED / INSUFFICIENT_DATA / UNKNOWN。

用 `scripts/stop-dev.ps1` / `bash scripts/stop-dev.sh` 停止，再用 `start-history` 对应脚本。打开 `/history/m1-core`，匿名、无数据库，明确「历史真实实验 · 已结束 · 非实时监控」。

## 质量与验证边界

复用全量 Maven、Vitest/strict/lint/正常与历史 build、Node、安全与幂等/并发测试、packaged Delivery smoke、H2 立即停止重启、历史 SHA、root harmless CI。具体 run 链接、跳过原因与失败修正记录以检查表/PR 为准，不能将 CI Java21 说成本机手工 Java21。

源码版本统一 `1.0.0-rc1`。本轮不发布签名二进制资产，本机 JAR SHA 不等于所有平台产物一致性的承诺。

## 已知限制与正式版前事项

- 本地 HTTP 仅 loopback；公网生产、密码管理/细粒度权限/多节点等加固未完成。
- Windows Node 子进程停止可能立即终止；Fake H2 同步提交刷盘，已提交记录重启可读回。未提交请求不保证完成，不自动重试；不承诺所有断电场景。
- macOS、真人首次密码交互、本机 JDK21 手工流程尚未完成，不标 PASS。Windows NTFS ACL 不由 chmod 代替。
- ESLint 现有弃用提示、ECharts >500KB chunk 警告；可后续维护，不扩大本轮冻结范围。
- 在发布 PR 审核/合并、对应 main CI、真人交互验收与单独 tag/Release 授权完成前，不公开 RC。`v1.0.0` 需要新的正式发布决定。
